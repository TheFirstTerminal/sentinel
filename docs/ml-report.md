# Sentinel ML classifier: evaluation

Generated by `go run ./cmd/mltrain` (2026-11-18). Model: logistic regression over hashed character 3-5-grams, words and word pairs (32768 slots), trained on 99118 examples (half attacks from 24 generated families and public payload lists, half normal input, generated and recorded from real sites). Threshold: 0.90.

> Most of the data is generated. The numbers show how the model behaves on fresh data from the same generator, on evasion variants and public payloads it never saw, and on real browser traffic from sites it never saw; your traffic will differ. Run Sentinel with `ML_MODE=detect` on real traffic first and check the log before blocking.
