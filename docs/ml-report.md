# Sentinel ML classifier: evaluation

Generated by `go run ./cmd/mltrain` (2026-11-10). Model: logistic regression over hashed character 3-5-grams, words and word pairs (32768 slots), trained on 50000 synthetic examples (half attacks from 24 families, half normal input). Threshold: 0.90.

> The data is generated, not captured from real traffic. The numbers show how the model behaves on fresh data from the same generator and on evasion variants it never saw; real traffic will differ. Run Sentinel with `ML_MODE=detect` on real traffic first and check the log before blocking.

## 4. CSIC 2010

On the CSIC 2010 dataset the model alone catches 14.9% of the anomalous
requests with no false alarms: most of them are parameter tampering without
attack syntax, which this model is not built to see. Sentinel's app profile
covers that case. Per-layer results are in
[`benchmarks.md`](benchmarks.md#1b-csic-2010).
