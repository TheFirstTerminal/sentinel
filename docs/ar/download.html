نزّل سنتينل

ملف واحد، ما يحتاج تنصيب. حطه قدّام تطبيقك وافتح الرابط اللي يطبعه. الزر المناسب لجهازك متأشر.

سنتينل المجاني

مجاني لأي عدد من السيرفرات، حتى بالإنتاج. الكود مفتوح، فتگدر تقرا بالضبط شنو يشتغل.

Docker: docker run -p 8080:8080 ghcr.io/thefirstterminal/sentinel. Homebrew: brew tap thefirstterminal/sentinel https://github.com/TheFirstTerminal/sentinel && brew install sentinel. كل طرق التنصيب، وشلون تتأكد إن الملف أصلي: ملف README (بالإنكليزي).

سنتينل Pro

تنزيلات Pro للزباين. الصق مفتاح الترخيص اللي وصلك، وتاخذ روابط لكل الأنظمة (تشتغل 10 دقايق، وتگدر ترجع تاخذ روابط جديدة أي وقت). ما عندك مفتاح؟ شوف شنو يضيف Pro والأسعار.

المفتاح ينفحص وما ينحفظ. لأي سؤال: support@tft.markets.
