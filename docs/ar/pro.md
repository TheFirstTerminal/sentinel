# Sentinel المجاني والـ Pro

[English](../pro.html)

**Sentinel المجاني** هو بوابة الحماية كاملة: كشف الهجمات (قواعد Sentinel، وقواعد OWASP، ونموذج التعلم الآلي)، والحماية من حقن الأوامر، وحدود الطلبات، والحظر، وفحص البوتات، وأكثر من موقع، وHTTPS تلقائي، ولوحة التحكم، والتنبيهات، وتصدير السجلات. ببلاش لأي عدد من السيرفرات، حتى بالإنتاج.

**Sentinel Pro** يضيف التحكم بالوصول: Sentinel يقرر منو يگدر يوصل لكل جزء من تطبيقاتك، مو بس أي طلب هو هجوم.

| | المجاني | Pro |
|---|---|---|
| جدار الحماية: قواعد Sentinel، وقواعد OWASP، ونموذج التعلم الآلي | ✅ | ✅ |
| حماية نقاط الذكاء الاصطناعي من حقن الأوامر | ✅ | ✅ |
| حدود الطلبات، الحظر، الفخاخ، فحص البوتات | ✅ | ✅ |
| أكثر من موقع، توزيع الحمل، HTTPS تلقائي | ✅ | ✅ |
| لوحة تحكم بتحقق بخطوتين، تنبيهات، syslog وOpenTelemetry | ✅ | ✅ |
| **تسجيل دخول موحد (SSO)** لتطبيقاتك (Google، Microsoft، Okta، Keycloak، أو أي مزود OpenID Connect) | | ✅ |
| **تسجيل دخول بتحقق بخطوتين** لتطبيقاتك، ويا الجلسات والخروج | | ✅ |
| **قواعد وصول** حسب الدور، والقسم، والملكية ("بس راتبك انت")، والوقت، والشبكة | | ✅ |
| **تحقق إضافي حسب الخطر**: بلد أو IP أو ساعة غريبة تطلب تحقق بخطوتين أو تنحجب | | ✅ |
| **شهادات العميل (mTLS)** للاتصال بين الخدمات | | ✅ |
| **سجل تدقيق ما ينلعب بيه**، يتفحص من لوحة التحكم | | ✅ |
| تطبيقك يعرف منو المستخدم (`X-Sentinel-User`، الدور، القسم) | | ✅ |
| دعم بالإيميل | | ✅ |
