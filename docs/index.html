What happens to a request

Cheap checks run first, so a banned address is turned away before any pattern is matched. You start in monitor mode: everything is checked and logged, nothing is blocked, until you've seen what it would do on your traffic.

  1. Who is asking

    Banned IPs, countries you don't serve, honeypot paths only scanners visit, known attack tools.

  2. How often

    Rate limits per path, password-spraying detection, an optional proof-of-work check for bots.

  3. What it contains

    Sentinel's rules after decoding evasions, the OWASP Core Rule Set, and an ML model for attacks no rule describes.

  4. What goes back

    Database errors, stack traces and keys in responses are withheld. Card numbers are masked.

Try it on your machine

Put Sentinel in front of an app on port 3000:

docker run --rm -it -p 8080:8080 -v sentinel-data:/var/lib/sentinel \
  -e UPSTREAM_URL=http://host.docker.internal:3000 \
  --add-host=host.docker.internal:host-gateway \
  ghcr.io/thefirstterminal/sentinel

Open the one-time link it prints to create your admin account. On a Linux server, one line installs it as a service; there are also Debian and RPM packages, Homebrew, Helm and plain binaries. Every way to install.
